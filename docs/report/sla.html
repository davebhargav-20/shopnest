1. What is an SLA?

A Service Level Agreement states how available a service should be, how quickly it recovers from a problem and what is not covered. AWS has its own SLAs for its services; ShopNest sets simple targets on top of them for a class-project demonstration.

5. Exclusions

The SLA does not cover: expiry or reset of the AWS Academy lab; an AWS regional outage; problems in the user's own network; resources stopped by the nightly auto-stop after the KeepAliveUntil date; periods when deployments are deliberately frozen; misuse of credentials or tags; and the lack of encryption between the browser and the website, because the site uses HTTP.

No uptime percentage is claimed: the system has run for a short time only, so long-term availability has not been measured.
